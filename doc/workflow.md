# 开发约定

## 小步前进

- 每一步只做一个功能点，规模以"一个人能逐行看完"为准。
- 每一步完成后给出审核清单：改了哪些文件、各改了多少行、重点该看什么。
- 清单交给作者审核，确认后才进入下一步。

## 审核

- 作者必须真正逐行审核代码，目的是保证项目简洁、高质量、符合作者想要的样子。
- 如果审核没有真的做过，协作的 AI 会要求回去补做。

## 谁写代码

- 日常开发主要交给 DeepSeek（通过 DSH）完成；Claude Code 负责派发、复核和验收。
- 每个任务单独说明可读写的范围；任务之间的写入范围不重叠。
- 关键节点由 Claude Code 亲自跑验收，而不只采信 DeepSeek 的自述。

## 语言与命名

- 提交信息：Conventional Commits，英文。
- 文档与说明：中文。
- 新建文件夹：英文、单数（`doc` 而不是 `docs`）。
- 代码：遵循 C# 通用习惯，注释保持精简。

## 不提交的内容

`.claude/`、`reference/`、`binary/`、`草稿纸.md`，以及任何含凭据的文件。
